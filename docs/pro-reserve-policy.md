# Opening reserve injuries and practice cleanup

October28 user policy: unknown opening medical reserves receive a four-game minimum; confirmed season-ending players remain unavailable for2026. This is a game initialization assumption, not a claim that all generic RES/DEV/INA source codes represent a diagnosed injury. Unsigned draft rights and non-medical EXE/SUSP restrictions are excluded. No unknown body area is assigned.

Eight reviewed reports are embedded with player/team, report date, description and URL in pro-opening-reserve-injuries.json: Jake Bobo, Matt Hennessy, Jayden Reed, Jaxson Dart, De'Von Achane, Brian Burns, Javon Hargrave and Tom Kennedy. Other opening medical reserves use the default. This is a reviewed subset, not an exhaustive medical census. Reports apply only to existing opening reserve players, not unrelated active players or later seasons.

ProReserveInjury stores placement year/team, baseline completed regular-season games, minimum games, season-ending flag and source/estimated status. Completed team games determine eligibility: preseason and byes do not count, manual/live and simulated games share saved results, and reloading does not restart the wait. The Finish retry guard prevents double recovery; explicit non-default injury recovery also decrements once per completed regular-season team game. CPU movement and GameCast availability use the same medical predicate. Eligibility is not automatic roster insertion: cap/roster/contract and role checks still apply. Overview inbox reports both blocked IR and readiness to activate. The player card/injury list explain remaining games or season-ending status. On annual rollover medical records clear along with existing season recovery.

Existing2026 saves without the version marker gain a season-start baseline only for source roster identities still in reserve. Players who have already missed four saved regular-season games are not locked for another four. Negotiated contracts and active players are untouched by medical initialization. The optional version/record fields preserve old JSON compatibility.

Oversized ordinary practice squads are reduced to16 by ascending overall, then older age and stable ID. Explicit international exemptions are retained. Cleanup runs for new current franchises and before calendar advancement, using normal release accounting so guaranteed/dead-cap obligations remain. CPU's six-veteran correction remains separate. No College rules or package/save formats change.

The game still uses simplified permanent practice assignments and does not claim a full NFL IR practice-designation/21-day window or temporary game-day elevation system. The four-game model follows the user-authorized default; medical return and season-ending state are now simulated rather than indefinitely blocked generic source codes.
