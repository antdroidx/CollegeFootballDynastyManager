# Build 232: animated Game Day and league matchup control

Game Day now presents each snap on a marked field with the line of scrimmage, first-down line, team-colored personnel, and a visible football. Players move from their formation through a route, run, block, or pursuit path while the ball advances to the recorded result. The scoreboard, clock, down, distance, possession, play call, and result update after every animated snap.

Play mode replaces the text-only call list with a visual two-column call sheet. Every choice includes its play art, formation, personnel, concept, and description. The currently selected call remains visible beside its diagram before the snap.

The Overview displays **Sim game**, **Watch game**, and **Play game** whenever the user's next game is available. The Game Day hub lists every league matchup for the active week. CPU-versus-CPU games can be watched, simulated individually, or played by choosing either team to control. Completed games save immediately and the ordinary week advance resolves games the user leaves unopened.

The viewer is an animated representation of the snap result rather than a physics simulation. It uses the same playbook, personnel, fatigue, coaching, ratings, and statistics engine in all three modes, so viewing or calling a game does not switch to a separate result model.
